## 新增条目流程

1. 复制 knowledge-base 的 `模板/条目模板与使用说明.md` 结构，中文命名 `领域-主题.md`（不带空格）
2. frontmatter 填 `tags / date / status / related / source`
3. 正文按 `TL;DR → 问题 → 根因 → 解决 → 预防` 写，末尾加 `## 来源`
4. 本索引加一行；`DEVELOPMENT.md` 第三节问题索引同步加行
5. 项目收尾 / 季度回顾时，挑跨项目通用的复制到 `knowledge-base/用户库/解决方案/`

## 隐私红线

公开仓库：禁止写入凭据（token / 密码 / API Key）、个人信息、本地绝对路径。`source` 只写 GitHub blob 链接。
