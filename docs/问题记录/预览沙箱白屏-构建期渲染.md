# 预览沙箱白屏-构建期渲染

**TL;DR**：预览器剥离/禁用脚本后，靠 JS 运行时生成的列表会变成 38 字空壳；把内容在构建期直接写进 HTML DOM 才是唯一稳的解。

## 问题

单文件新闻页在普通浏览器里正常，放进对话预览器后反复白屏、看不到内容。本地把浏览器 JavaScript 关掉复现：整页可见文本只剩 38 字（导航外壳），新闻列表与正文全部消失。

## 根因

1. 页面把 CSV 解析、列表渲染、路由都放在 `<script>` 里，HTML 响应本身没有新闻 DOM
2. 对话预览普遍把页面塞进 `sandbox="allow-scripts"` 的 iframe，还可能剥离内联脚本或注入 `connect-src 'none'` 的 CSP
3. 即使允许脚本，运行时 `fetch` 读本地 CSV / 公共代理也会被 CSP 在网络层拦掉
4. 把 150 KB HTML 当作超长 `srcdoc` **属性**拼接还会让浏览器崩（长属性注入限制，Blob URL 注入则正常）

## 解决

新增 `build_static.py`，构建期把 `articles.csv` 的 23 条新闻与 7 篇正文直接写成 HTML DOM：

```python
# 生成器：内容写进响应，而非运行时再取
parts.extend(card(r, i) for i, r in enumerate(rows))
OUT.write_text(doc, encoding="utf-8")   # index.html 零 <script>
```

- `index.html`：零 `<script>` / 零 fetch / 零 localStorage，51 KB
- `zaker-news.html`：`#main` 内注入同一份兜底 DOM；JS 可用时 `render()` 覆盖，被拦时原样可读
- `<noscript>` 隐藏搜索框、频道条、标签栏等空控件

实测：禁用 JS 下 7459 字 / 23 卡 / 55 段正文；`file://` 双击同样；Blob URL iframe 沙箱零报错。

## 预防

- 判断"能不能在预览里看"的第一问永远是：**内容在 HTML 响应里吗？**
- `<noscript>` 只能提示，不能渲染数据；别把它当兜底方案
- 自包含页面控制在 60 KB 量级，避开长 `srcdoc` 属性注入
- 每次改动跑一遍"禁用 JS + 沙箱 iframe + file://"三件套验证
